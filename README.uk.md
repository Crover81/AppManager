# AppManager

**Керуйте іграми та програмами у Windows і видаляйте їх повністю.**
AppManager видаляє гру чи програму, а потім знаходить усе, що вона та Windows залишили після себе: збереження, налаштування, кеш, знімки екрана, записи реєстру, елементи автозавантаження, завдання планувальника, служби, типи файлів, пункти контекстного меню, правила брандмауера та ярлики. Нічого не видаляється, доки ви не побачите список і не підтвердите.

## Коротко

- **Усе встановлене в одному місці**: Steam, Epic Games, GOG, Ubisoft Connect, EA app, Battle.net, Rockstar, Amazon Games, Xbox / PC Game Pass, застосунки Microsoft Store, звичайні інсталятори, репаки та **портативні** копії.
- **Видалити й очистити**: запускає потрібний деінсталятор, чекає на його завершення і показує кожен залишок за категоріями, з причиною, чому його знайдено, і ступенем упевненості AppManager («Точно», «Імовірно», «Перевірити»).
- **Залишки застосунків, яких уже немає**, зокрема ігор, видалених вручну.
- **Спостереження у фоні** (за бажанням): стежить за встановленням і видаленням програм з області сповіщень і повідомляє, якщо після видалення щось лишилося.
- **Менеджер збережень**: резервні копії, кілька профілів збережень для однієї гри, «нова гра» без втрати старої.
- **Безпека понад усе**: Кошик і zip-копія перед видаленням, захищені системні області, нічого не видаляється без вашого підтвердження.
- **Завжди портативна**: усе зберігається в папці `Dati` поруч із програмою; кожен ПК має власний профіль.

## Знімки екрана

На знімках англійська версія; програма використовує мову Windows.

### Огляд
ПК з першого погляду: скільки він працює, коли встановлено Windows, що змінилося з останнього запуску, місце на дисках і що займає найбільше. Список ігор і програм можна експортувати в CSV.

![Огляд](docs/images/overview.png)

### Ігри
Усі встановлені ігри з обкладинкою, розміром і лаунчером. Панель подробиць показує папку, видавця й те, як було знайдено гру, і дає швидкий доступ до збережень, видалення, запуску, папки та блокування інтернету. Відсутні обкладинки шукаються в мережі (Steam, PCGamingWiki, необов'язковий ключ SteamGridDB, Вікіпедія). Якщо обкладинки немає, використовується значок гри.

![Ігри, світла тема](docs/images/games-light.png)

Ігри знаходяться навіть без лаунчера: за слідами ігрових рушіїв (Unity, Unreal, CryEngine, Source, RPG Maker, Ren'Py…), за сигнатурами кряків та емуляторів Steam (CODEX, RUNE, EMPRESS, Goldberg…), за назвами репаків, за іграми, доданими до Steam вручну, і за виконуваними файлами, які Windows пам'ятає як запущені, де б вони не були.

### Програми
Встановлені програми, застосунки Microsoft Store, інструменти Steam і портативні програми. Середовища виконання, драйвери та вбудовані застосунки Windows приховано за посиланням «Показати компоненти Windows», щоб їх не видалити помилково. Портативну програму всередині проєкту розробки чи папки з документами пропонується видалити лише як її виконуваний файл, ніколи як усю папку.

![Програми](docs/images/programs.png)

### Видалити й очистити
AppManager запускає правильне видалення (Steam, деінсталятор програми, Windows для застосунків Store, пряме видалення для портативних копій). Коли воно завершиться, він шукає залишки.

![Підтвердження видалення](docs/images/uninstall.png)

Залишки згруповано за категоріями. Елементи «Точно» та «Імовірно» вибрано заздалегідь, елементи «Перевірити» — ні. Те саме вікно, відкрите кнопкою **Дані**, показує дані гри чи програми, нічого не видаляючи.

![Перевірка залишків](docs/images/leftovers-review.png)

Що шукається, окрім папок із даними в `AppData`, `ProgramData` і «Документах»:
- елементи автозавантаження (Run, RunOnce, стан у диспетчері завдань, папка «Автозавантаження»), завдання планувальника та служби програми;
- типи файлів, пункти «Відкрити за допомогою», застосунки за замовчуванням, контекстне меню, компоненти COM і розширення оболонки;
- папки, додані до `PATH`, налаштування сповіщень, історія запусків, сумісність, налаштування GPU, правила брандмауера;
- для ігор: дані Steam, папки Unity та Unreal, збереження в `My Games` і «Збережених іграх», папки емуляторів Steam, кеш шейдерів.

Системні записи пропонуються, лише якщо вони справді належать програмі: усе, що вказує на Windows, ніколи не чіпається.

### Залишки вже видалених застосунків
Один аналіз знаходить залишки ігор і програм, які більше не встановлено або які видалено вручну, і розподіляє їх між розділами «Ігри» та «Програми». Явно осиротіле вибирається; нещодавно використані дані без такого доказу лишаються «Перевірити».

![Залишки](docs/images/leftovers.png)

### Спостереження у фоні
За замовчуванням вимкнено. Якщо його увімкнути, AppManager запускається разом із Windows і лишається в області сповіщень. Він стежить за записами видалення Windows і бібліотеками Steam та Epic. Коли програма чи гра зникає, він чекає на завершення деінсталятора і шукає залишки.

![Історія спостереження](docs/images/monitoring.png)

Якщо щось лишилося, над областю сповіщень з'являється сповіщення, яке не закриває панель завдань. **Переглянути й видалити** відкриває список, **Ігнорувати** закриває його. Сповіщення зникає через 20 секунд і чекає, поки триває повноекранна гра чи презентація. Якщо видалення йдуть одне за одним, те саме сповіщення збирає їх усі. Сторінка **Спостереження** зберігає історію: встановлення, оновлення та видалення, зокрема зроблені через AppManager, з тим, що лишилося, і тим, що вже видалено. Спостереження ніколи нічого не видаляє саме.

![Сповіщення](docs/images/notification.png)

### Збереження та профілі
Для кожної гри **Керування збереженнями** саме знаходить папки збережень: Steam, `My Games`, «Збережені ігри», `AppData`, папки Unity та Unreal, папки емуляторів Steam, якими користуються неофіційні копії, і папку самої гри, куди зберігають багато портативних копій. Для збережень, які не можна розпізнати за назвою, воно звертається й до PCGamingWiki; надсилається лише назва гри.
- **Резервні копії збережень** у zip-файлах, які можна відновити будь-коли. Перед кожним відновленням спершу зберігається копія поточних збережень.
- **Профілі**: кілька наборів збережень для однієї гри, наприклад по одному для кожного гравця.
- **Нова гра**: відкладає поточні збереження й починає з нуля; повернутися до попереднього профілю можна будь-коли.

![Збереження](docs/images/saves.png)

### Автозавантаження та мережа
**Автозавантаження** показує програми, що запускаються разом із Windows, і вмикає чи вимикає їх, як диспетчер завдань. Вимкнення нічого не видаляє.

![Автозавантаження](docs/images/startup.png)

**Мережа** в реальному часі показує, які запущені програми під'єднані і куди. Можна заблокувати один напрямок або весь доступ програми до інтернету через брандмауер Windows. Кожне правило знімається одним клацанням у налаштуваннях.

![Мережа](docs/images/network.png)

### Налаштування
Тема (світла, темна або як у Windows), мова, обмеження місця для завантажених зображень, типові значення для Кошика й резервної копії, спостереження у фоні, портативні папки, способи пошуку та мережеві правила.

![Налаштування](docs/images/settings.png)

## Безпека

- **Нічого не видаляється без вашого підтвердження.** Ви завжди бачите повний список із причиною та ступенем упевненості для кожного елемента.
- **Кошик і резервна копія**: за замовчуванням видалені файли потрапляють до Кошика, в окрему папку для кожного застосунку, з повними шляхами. Туди ж зберігаються системні записи — у вигляді файлів `.reg`, `.xml` і `.txt`. Збереження, налаштування та системні записи також копіюються в zip-архів, який можна відновити в розділі **Резервні копії**. Якщо копія не вдалася, очищення не починається.
- **Захищені області**: Windows, основні папки Program Files і ProgramData, компоненти Windows, папки користувача («Документи», «Робочий стіл», «Завантаження», AppData…), системні папки в корені дисків, лаунчери та папки всіх встановлених ігор і програм. Папка, що містить захищену, ніколи не видаляється.
- **Посилання ніколи не відкриваються**: видаляється лише сама точка з'єднання чи символьне посилання, а не те, на що воно вказує.
- **Незвичні шляхи** (короткі імена, змінні, `..`, мережеві шляхи та `\\?\`) перед будь-якою перевіркою зводяться до справжнього шляху або відхиляються. Шляхи, довші за 260 символів, підтримуються.
- **Лише одна копія програми одночасно**, налаштування зберігаються атомарно, кожна операція записується в журнал дій.

## Конфіденційність

AppManager виходить в інтернет лише для пошуку обкладинок ігор і папок збережень. Для збережень він звертається до PCGamingWiki і надсилає лише назву гри. Обидва пошуки можна вимкнути. Необов'язковий ключ SteamGridDB надсилається лише до SteamGridDB. Телеметрії немає. Кожен ПК розпізнається за анонімним відбитком його ідентифікатора Windows; сам ідентифікатор ніколи не зберігається й не надсилається.

## Завантаження та використання

1. Завантажте `AppManager.exe` зі сторінки [останньої версії](../../releases/latest).
2. Покладіть його в будь-яку папку, навіть на флешку, і запустіть. Windows попросить права адміністратора; вони потрібні для Prefetch, системних розділів реєстру, служб, системних завдань планувальника та правил брандмауера. Без них AppManager працює в «Обмеженому режимі» і все одно знаходить та очищає дані вашого користувача.

Вимоги: Windows 10 або 11. Використовується .NET Framework 4.8, що вже входить до Windows. Для оновлення замініть `AppManager.exe`: папка `Dati` лишиться.

**Клавіатура**: Ctrl+F пошук · F5 оновити · Del видалити вибраний елемент (відкриває лише підтвердження) · Esc закрити · Enter підтвердити (ніколи для дій, які щось видаляють).

## Збирання з вихідного коду

Visual Studio не потрібна: достатньо компілятора C#, що входить до Windows (C# 5, .NET Framework 4.8).

```
cd Source
powershell -ExecutionPolicy Bypass -File build.ps1
```

`build.ps1 -AsInvoker` збирає `bin\AppManager.Test.exe` без запиту прав адміністратора, для тестів. `build.ps1 -Harness` також збирає `tools\Harness.exe`, консольний інструмент перевірки:

| Команда | Що перевіряє |
|---|---|
| `robust <папка>` | крайні випадки: захищені шляхи, посилання, довгі шляхи, імена в Unicode, заблоковані файли, змінені резервні копії (лише тестові дані) |
| `invariants` | лише читання: усе, що аналізи пропонують на цьому ПК, дотримується правил безпеки |
| `savetest <папка>` | менеджер збережень: копії, нова гра, зміна профілю, відкат у разі помилки, відновлення |
| `recycletest <папка>` | Кошик, упорядкований за застосунками, без використання справжнього Кошика |
| `pctest <папка>` | розпізнавання ПК, ресурси, автозавантаження, експорт, переклади, виявлення піратських і портативних копій, логіка спостереження |
| `logtest <папка>` | журнал дій |
| `watchtest <папка>` | повна перевірка спостереження з тестовим застосунком, який тест створює, а потім видаляє |

Для `pctest`, `logtest` і `watchtest` змінна `APPMANAGER_DATA` має вказувати на ту саму тестову папку; для `savetest` і `recycletest` — на іншу.

### Структура проєкту

```
Source/
  src/core   виявлення, пошук залишків, очищення, резервні копії, збереження, спостереження (без інтерфейсу)
  src/app    ViewModel для WPF, значок в області сповіщень, сповіщення
  ui         XAML (завантажується під час запуску) і переклади в ui/lang/*.txt
  tools      консольний інструмент перевірки (Harness)
  build.ps1  сценарій збирання
docs/images  знімки екрана
```

Тексти в коді та XAML написано італійською, і вони слугують ключами; переклади містяться в `ui/lang/*.txt`.
